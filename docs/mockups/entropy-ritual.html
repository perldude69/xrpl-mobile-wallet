Entropy ritual — create wallet

Prototype of the flow we discussed: swipe-driven dice, a personal “random word,” then mix with OS secure random into a 256-bit BIP39 seed.

  • Swipe across the felt to throw five dice. Speed, path, and timing feed the user pool.
  • Type any unpredictable phrase; we hash UTF-8 bytes (not just hex of the string).
  • Always mix with device CSPRNG so a weak word or few rolls cannot break the wallet.
  • Then: reveal 24-word phrase → backup quiz (same as today).
Security note for the real app: dice + typed text are extra entropy and user ceremony — they must never be the only source. Final seed = SHA-256(OS ‖ swipe-metrics ‖ dice ‖ word-hash) (or HKDF). This HTML only simulates that with Web Crypto for the demo.
