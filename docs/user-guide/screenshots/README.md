# Screenshot files for the user guide

Drop PNG captures here using the exact filenames listed in
`docs/user-guide/index.html` (the **SHOT** cards). Until a file exists, the
HTML guide shows a labeled placeholder.

Suggested capture: Pixel 8 Pro, portrait, dark theme, no notification shade.

Still needed from a device (not in this folder yet): `01-home-icon.png` (app drawer / home with the outlined-Z launcher icon). FLAG_SECURE screens (create / import / send) may stay as HTML placeholders until captured with screen security off.

Screens marked **FLAG_SECURE** (PIN, create, import, add keys) may come out
black with the system screenshot tool. Capture those from a debug build or
with screen security temporarily off.
