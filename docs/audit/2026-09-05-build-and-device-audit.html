Findings and residual risk

  1. Low, XRW-24: the create-wallet flow offers clipboard copying of the recovery phrase (lib/ui/wallets/create/create_wallet_screen.dart:263-271). The UI warns the user and clears clipboard data when leaving, but clipboard exposure remains possible.
  2. Informational, XRW-25: several UI error paths display raw exception text (lib/ui/send/send_screen.dart:226, lib/ui/wallets/import/import_screen.dart:99-101). This can expose implementation/provider details to users and should be mapped to safe messages.
  3. Build note: Gradle reported upcoming support deprecation for Gradle 8.14, AGP 8.11.1, and Kotlin 2.2.20. This did not affect this build.

Limitations
